# HIAD 2.2 웹 데이터셋 구축 프로그램 v0.7.0 (IDLE 실행 지원)

Flask와 Python으로 구현한 HIAD 2.2 기반 EHSP 다중라벨 학습데이터셋 구축용 1–7단계 로컬 웹 프로그램입니다.

## 포함 기능

1. 프로젝트 생성 및 재접속
2. `.xlsx`·`.xlsm` 업로드와 형식·용량 검사
3. 전체 시트명, 행 수, 항목 수와 항목명 탐색
4. 논문 v1.0.0 기준 시트·6개 항목 자동 선택
5. 사용자 선택 변경과 중복·누락 검사
6. 입력파일 SHA-256, 기준값, 실제 선택값, 확정시각 저장
7. 1단계 실행 설정 JSON 다운로드
8. 원본 파일 해시, 필수 시트·항목 검증
9. 사건 ID 결측·중복 및 품질등급 허용값 검증
10. 분석 텍스트 결측, 분석 가능·제외 대상 사건 수 산출
11. 검증 결과 통과·주의·오류 표시
12. 2단계 검증 JSON·CSV 다운로드 및 프로젝트 재접속
13. `Summary root causes`의 EHSP C01～C08 표준화
14. 다중라벨 분리, C08 배타성 및 미매핑 검사
15. 사건별 8개 이진열·표준코드 CSV와 요약 JSON 다운로드
16. 미매핑·빈 라벨 검토대상 CSV 다운로드
17. v1.0.0 기계판독형 코드북에 따른 후보라벨 생성
18. 규칙 ID·출처·신뢰수준·근거 문장 기록
19. 원본 표준라벨과 후보라벨의 일치·추가·누락 비교
20. 4단계 요약 JSON과 후보·근거·비교 CSV 다운로드
21. 후보–원본 차이 216건의 사건별 비교검토
22. 기존 유지·후보 채택·합집합·직접 지정·제외 결정
23. 사건 원문, 후보 규칙 및 근거 문장을 한 화면에서 확인
24. C08 배타성, 필수 판정 사유 및 검토자 ID 검사
25. 검토 결과 자동 저장, 중단 후 재개, 진행률 및 상태 필터
26. 5단계 요약 JSON과 비교검토 결과 CSV 다운로드

## Windows 실행

Python 3.8 이상을 설치한 뒤 `Windows_최초설치.bat`를 한 번 실행합니다. 이후 `Windows_실행.bat`를 실행하고 `http://127.0.0.1:5000`에 접속합니다.

### Windows IDLE에서 실행

1. 최초 한 번 `Windows_최초설치.bat`를 실행하여 필요한 패키지를 설치합니다.
2. `app.py`를 마우스 오른쪽 버튼으로 눌러 **Edit with IDLE**로 엽니다.
3. IDLE 메뉴에서 **Run → Run Module**을 선택하거나 `F5`를 누릅니다.
4. 서버가 시작되면 기본 브라우저에서 `http://127.0.0.1:5000`이 자동으로 열립니다.
5. 종료할 때는 IDLE Shell에서 `Ctrl+C`를 누르거나 Shell 창을 닫습니다.

브라우저가 자동으로 열리지 않으면 주소창에 `http://127.0.0.1:5000`을 직접 입력하면 됩니다. 서버 실행 중 `app.py`를 다시 실행하면 5000번 포트가 사용 중이라는 오류가 발생하므로 기존 실행을 먼저 종료해야 합니다.

## Ubuntu 실행

터미널에서 `chmod +x Ubuntu_*.sh`, `./Ubuntu_최초설치.sh`, `./Ubuntu_실행.sh` 순서로 실행합니다.

## 저장 위치

입력 파일과 SQLite 데이터베이스는 실행 후 생성되는 `data` 폴더에 저장됩니다. 원본 Excel의 내용은 수정하지 않습니다. 새 파일로 교체하면 확정했던 기존 1단계 설정은 폐기되고 다시 선택해야 합니다.

## 논문 기준 기본값

- 사건 시트: `EVENTS`
- 분류기준 시트: `Classes for EVENTS`
- 항목: `Event ID`, `Q`, `Event Title`, `Event full description`, `Summary root causes`, `Root CAUSE analysis`

본 버전은 입력 구조 설정, 입력자료 검증, 원본라벨 표준화, 후보라벨 생성, 비교검토, 무후보 사건 검토 및 최종 다중라벨 학습데이터셋 생성에 이르는 1–7단계 절차를 구현합니다.
