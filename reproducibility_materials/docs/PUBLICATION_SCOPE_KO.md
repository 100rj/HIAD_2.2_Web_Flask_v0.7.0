# 검토결과 파일 및 연구자료의 공개범위

## 공개하는 자료

1. 프로그램 실행구조를 보여 주는 비식별 설정파일 예시
2. 비교검토와 무후보 검토에 사용할 수 있는 빈 입력양식
3. 합성사건으로 작성한 예제 검토결과
4. 합성 예제 입력자료와 예제 출력자료
5. 예제 실행의 프로그램 버전·입력·출력 정보를 기록한 매니페스트
6. 공개된 예제파일을 대상으로 실제 계산한 SHA-256 해시목록

## 공개하지 않는 자료

1. 원자료 제공기관의 이용조건이 적용되는 HIAD 2.2 원본 Excel 및 그 복제본
2. 원자료의 사건기술을 그대로 포함하여 역식별이나 재배포 문제가 생길 수 있는 중간·최종 산출물
3. 실제 검토자의 성명, 연락처, 서명, 계정명 및 개인식별 가능한 검토자 ID
4. API 키, 비밀번호, 토큰, `.env`, 서버 비밀설정 및 개인별 실행경로
5. 실행 중 생성된 SQLite DB, 업로드 임시파일, 세션자료 및 로그 중 민감정보가 포함된 파일

## 실제 검토결과의 제공 원칙

공개 저장소에는 빈 검토양식과 합성 예제만 제공한다. 실제 검토결과는 원자료 이용조건, 개인정보·연구윤리 및 기관의 공개승인을 확인한 뒤 사건기술과 검토자 정보를 비식별화한 범위에서만 제공한다. 독립 연구자에게 추가 자료를 제공해야 하는 경우에도 동일한 승인과 이용조건을 적용하며, 공개 여부와 제공 범위를 별도로 기록한다.

## 해시 해석

`SHA256SUMS.example.txt`는 이 폴더에 포함된 합성 예제파일의 무결성 검증용이다. 논문 본 분석에서 생성된 핵심 산출물의 해시는 본 실행파일에서 별도로 계산·보존해야 하며, 예제 해시를 본 실행 해시로 인용하거나 대체하지 않는다.
