# Manifest and hash files

`run_manifest_example_v0.7.0.json` records a public synthetic format example associated with the v0.7.0 repository. The example outputs were prepared with the supplementary reproducibility builder and are not represented as a full v0.7.0 web execution. `SHA256SUMS.example.txt` contains hashes calculated from the files included in this folder. These values verify only the public synthetic examples and must not be represented as hashes of the restricted HIAD 2.2 research data or the paper's actual full run.
